## Description

> A browser-based audiovisual homage to *WarGames* (1983): modem dialing,
> vector command displays, WOPR, global thermonuclear war simulations, and the
> only winning move. All graphics, CRT treatment, animation, text, and vector
> displays are rendered in real time with HTML5 Canvas.

## Technical notes

- TypeScript, HTML5 Canvas, Vite, Web Audio API
- Custom ProTracker MOD parser/player
- Modern desktop browser; audio starts after a click or key press
- Extract and serve with any static HTTP server; no build step is needed
